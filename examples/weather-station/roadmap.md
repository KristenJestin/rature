# Roadmap

What the station does next, roughly in order. Done items stay here until the next release.

## Version 0.3

- [x] Send readings over LoRa instead of Wi-Fi
- [x] Average the last readings (see [Sensors](sensors.md))
- [ ] Report the battery voltage
- [ ] Skip the upload when the battery is low

## Version 0.4

- [ ] A second station at the bottom of the garden
- [ ] Frost warning on the receiver
  - [ ] when the [dew point](sensors.md#dew-point) falls below 0 °C
  - [ ] and the wind is calm

> [!TIP]
> An idea that is not on this list belongs in the issue tracker first.

## Not planned

- A display on the station itself: it would drain the battery.
- Forecasts. The station measures; it does not guess.
